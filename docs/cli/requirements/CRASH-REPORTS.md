# 崩溃捕获与取证（CRASH-REPORTS）· CLI 面 · 需求

> 板块 = **崩溃捕获与取证**——CLI 进程崩溃时的诊断留痕（JS 异常记录 / Node 诊断报告 / TUI stderr 捕获 / 近堆上限堆快照 / 堆遥测预警 / 异常退出终端恢复）。
> 配对设计档 = `docs/cli/design/CRASH-REPORTS.md`（机制权威）。
> 层归属 = **CLI 面**（P2——VSC 端无此面）。

## 1. 总体需求

CLI 进程崩溃时（含 JS 钩子拦不住的面：V8 原生 OOM / abort、外部终止），**事故现场默认留下可检索、可回传的诊断证据**
——不依赖复现、不依赖用户事先开任何开关（**F3 对象级快照除外**——默认关、需显式开启：隐私面见 F3 ②；「谁在持有内存」一问答随 F3 开启）。目标问题：「崩在哪、谁在持有内存」必须能在事后回答；
取证能力本身不得影响正常运行（尽力面）。

**证据构成（按崩溃类型）**：JS 异常 / 未处理拒绝 → 记录文件（F1）· V8 fatal → Node 诊断报告（F1）·
外部终止 / native abort → stderr 捕获（F2）· **堆耗尽 → 对象级快照（F3）** · **堆爬升 → 事前预警（F4）** ·
**异常退出 → 终端恢复（F5）**。

## 2. 功能性需求

| # | 需求 | 说明 |
|---|---|---|
| **F1** | 崩溃留痕（存量） | JS 异常钩子写 `crash-*.json`；`process.report` 启用（fatal 自动写 `report.*.json`）；启动「上次异常终止」提示（24h 窗） |
| **F2** | TUI stderr 默认捕获（存量） | TUI 启动 = 父进程包装 spawn 子进程（自身），子 stderr tee 双写（终端 + `tui-stderr-*.log`） |
| **F3** | **近堆上限堆快照固化** | 堆接近 V8 上限时自动落一份对象级证据（`.heapsnapshot`——回答「谁在持内存」；Node 诊断报告只有分区统计、无对象级）。**默认关闭（取证 opt-in——隐私默认）**、固化进启动链——判定面见下 |
| **F4** | **堆遥测 / 看门狗** | 运行期周期采样堆用量、按**堆上限比例**给阈值预警（边缘触发——每阈值档一次）：默认开启、**可关（配置键 `diagnostics.heapWatch` 取 `false`）**、可注入（测试缝）；预警面 = stderr 行 + TUI 行 + 诊断事件；**只看不治**——判定面见下 |
| **F5** | **异常退出的终端恢复** | 包装父进程在子进程**非零 / 信号退出**时向终端补发恢复序列（与正常清理序列同源）——修「V8 fatal 不走 JS 钩子 → 鼠标上报未停 → 滚动飞数字串」次生面。判定面见下 |

**F1 判定句**

- ① **提示行事实面**：启动「上次异常终止」提示须带记录内 `uptime`（运行秒数）+ `cwd` 两段（可得时展示；字段缺 / 型不符 ⇒ 对应段略去——退化 = 基础形）；机检锚 = T7（两段在场）+ T7c（退化）。

**F3 判定句**

- ① **武装径（显式开）· 全路径**：`diagnostics.heapSnapshot` 取 `true` 时——任意 CLI 命令（TUI 子进程 / chat / acp / 其余）启动后近上限快照已武装——
  判定 = 注入缝断言「`v8.setHeapSnapshotNearHeapLimit` 以参数 1 调用恰一次」（真快照不跑——见 N4）；
  武装点 = 入口最前 `prepareCrashReporting()`（全部命令同源）。
- ② **可开（opt-in）**：配置键 **`diagnostics.heapSnapshot`** 取 `true` → 武装；未设 / 其余值 / 读失败 → **不武装**（默认关——隐私默认〔traces D-TR6 同族〕；判定形 fail-closed）。
- ③ **落点与可见**：TUI 路径（主路径 = 实测崩溃路径）快照落 `~/.thincoder/crash-reports/`（与既有取证物同处——经子进程
  `--diagnostic-dir` 定向）；其余路径落进程 CWD（Node 默认）。写出时 Node 原生 stderr 行 `Wrote snapshot to <路径>`
  （TUI 经 F2 的 tee 上屏 + 落日志）——用户 / 同事可截图回传。
- ④ **代价可知**：设计档落代价与取舍——体积 / 耗时 / 额外内存 / 次数上限 / 常态开销；
  不固化 `--max-old-space-size`（改堆上限会改变崩溃时机）。

**F4 判定句**

- ① **默认武装**：入口启动后看门狗在跑（注入缝断言：定时器恰注册一次；无堆压时零输出）。
- ② **可关**：配置键 **`diagnostics.heapWatch`** 取 `false` → 不启动；未设 / 其他值 → 启动（默认开——遥测默认面）。
- ③ **预警形态**：堆用量跨过阈值比例（设计档定值——比例制）→ 恰一次预警行（stderr 逐字 + TUI 行逐字——设计档；
  边缘触发不重复、跨档各一次）；未跨阈值零输出。
- ④ **开销与可移植**：阈值按 `heap_size_limit` 比例（无绝对 MB 常量）；周期采样常态开销可忽略（设计档落数字）。

**F5 判定句**

- ① **异常退出补发**：子进程非零 / 信号退出 → 恢复序列在父退出前下发（注入缝断言：写入串含 `mouseOff` 与 `mainBuffer` 序列——逐字）。
- ② **正常退出零干预**：子进程 exit 0 → 不补发（子自身清理序列为准）。
- ③ **失败面**：spawn error / 包装未启用 → 零动作（不写序列）。

## 3. 非功能性需求

| # | 维度 | 标准 |
|---|---|---|
| **N1** | 尽力面不阻断 | 武装失败 / 快照写失败不阻断启动与运行（独立 `try/catch`）；失败静默 |
| **N2** | 零常态开销与零回归 | 未近上限零快照行为、零周期开销（回调仅注册一次）；F1 / F2 既有行为零变化；非 TUI 命令除「CWD 可能出现快照文件」外行为零变化 |
| **N3** | 清理与判定集 | crash-reports 内 `Heap.*.heapsnapshot` 纳入 30 天写时自清理（与 `tui-stderr-*.log` 同族）；**不计入**「上次异常终止」提示判定集（不因快照文件误报） |
| **N4** | 测试口径 | 注入缝断言（武装 / 开关矩阵）替代真实快照；真快照不随集成测试跑（污染且拖慢）；Node API 存在性守护（Node ≥ 24 基线） |
| **N5** | 遥测零常态可感 + 零回归 | 看门狗周期采样开销可忽略；关值 / 未武装时零额外行为；既有命令输出面除预警行外零变化 |
| **N6** | 遥测 / 恢复可机判 | 均以注入缝断言（假采样器 / 假时钟 / 假写端）；不依赖真实堆压与外进程 |

## 4. 范围边界（不做）

- 不做泄漏根因修复（崩溃取证只保证「崩了有证据」）。
- 不固化 `--max-old-space-size` 或调整上限（改变崩溃时机）。
- 不做启动提示行（写时原生行 + 落点表 + 30 天清理已闭环——避免常态化噪音）。
- 不做非 TUI 路径落点改向（无运行时定向手段；不为此引入双击进程）。
- 不做 VSC 端对应能力；不做快照对比面（份数 = 1）；不做快照压缩 / 自动上传 / 自动删除 CWD 快照。
- 不做系统通知 / 终端标题改写等额外告警面（预警面 = stderr + TUI 行 + 事件日志）。
