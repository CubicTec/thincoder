> **卷**：桌面端需求分卷之「输入区域」——**D6 ∥ D13 ∥ D25 ∥ D34**（4 条）。
> **总览 ∥ D 表索引**：`docs/desktop/requirements/PROJECT.md`（D1–D42 全表查卷口；模块目标 / 定位 / 界面形态 / 边界 / 非功能 / 验收 / 依赖）。**同族设计档**：`docs/desktop/design/COMPOSER.md`。

## 功能点

| # | 功能点 | 判据（可机检） |
|---|---|---|
| D6 | 模型与档位 | 渠道行 → 模型条目两级菜单（**选取单位 = 模型条目**——渠道行非可选）、推理档位（含 Auto / off 族）、effort 菜单与回执一致；**一级 = 全部已配置渠道**（有 key 渠 ∧ 探通；探不通 ∕ 零 key ⇒ 零行——判据全式 = `docs/desktop/design/IPC.md` §2「模型清单注」）；**会话选定写回**：用户显式选定（槽面实变）⇒ 同拍写回 config `defaultModel = "<provider>:<model>"`（**新会话起点随用户最后一次显式选择**）；系统回声（会话切换 ∥ 候选推送）· 系统回退自动采用 · 仅改档位 · 复合等值 ⇒ **零写**——判据单源 = `docs/core/design/SESSION.md` §6.21 判据句 6（端侧契约 = `docs/desktop/design/IPC.md` §2「会话级偏好注」项 8）；**CLI ∥ VSC 推广**（用户「要」）：端契约 = `docs/cli/design/TUI-COMMANDS.md` §5.3 ∥ `docs/vsc/design/WEBVIEW.md` §4.10 |
| D13 | 会话素材与导出 | 附件（贴图 / 粘贴 → 落盘 + **非视觉模型降级面**）· **代码块复制**（核件 Copy 钮——与 VSC 同形）；`msg:send` 载荷须扩 images 维度；**附件面扩文本/源码档**：选择器受纳文本/源码族（扩展名清单 + `text/*`）；单档 ≤256 KB · 每回合 ≤4 档 ∧ 合计 ≤512 KB；发送时内联（`[Attached file: 名]` + fenced 段）入用户消息；拒面（超大/超数/合计超/二进制/类型不支持/读取失败）一律出声；图片道零改。 |
| D25 | 回合中插入（步边界 pickup） | 忙态提交 ⇒ **按会话键入队**（回执 `queued`；`busy` 拒收窄）；**消费前流内零块**（全输入径——待发送件住输入区上方带，含挂起窗径）；**步边界取批注入**（核缝只接不改——`pushReal` 普通消息 · 不中断 · 下一步生效）；**回合尾续发兜底**；**满 8 拒收**（忙态队满 **8** 条 ⇒ 提交拒 + 提示（词键 `input.slotFull`）+ 文本保留；端门判据 = 宿主镜像计数如实直读，同 tick 空窗以宿主权威兜底）；**队列 = 宿主单源 + 渲染面镜面**（快照 `ev:queue`——两源共镜：忙态队 ∪ 挂起窗队）；**附件条目携图**（步边界让位 · 送达面判决）；验收 = 机检 AC-1 / AC-2 + 真机 `T-DSK45` |
| D34 | 斜杠命令族 | 桌面 composer **认 slash 命令**——首例 `/model`（开模型菜单，与 chip **同菜单同门**）；**行为标杆 = CLI 实形**；**5 条**（`/model` `/auto` `/plan` `/eng` `/help` + 别名 `/m` `/p` `/h`——`/help` ∥ `/h`（用户直斥后拉回；流内打印形照 CLI 实盘）；回落 = toast + 文本保留（与 CLI「清框 + 流内错误行」的差异在册）；机制 = 核共享层（`thincoder-render-core`），命令表归端 |
