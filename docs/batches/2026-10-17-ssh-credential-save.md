### 机制设计（摘要——**单源 = 设计档 §6.22 ⑩⑪⑫**，本节不重述）
- **优先级铁序**（A 的机制保证）：本机配置 / agent ∥ `-i` ⇒ 探连 → 仅认证类失败才读保存件 → 仍失败才落窗。密钥可用 ⇒ 保存件**零读取**（S7 判据 = 读次探针 0）。
- **保存件**：`configDir/ssh-credentials.json`（用户域私档，仓库零落点；与 `ssh-hosts.json` 分档）；条目 = `{user, scheme, blob, savedAt, lastUsedAt?}`（读键 `host[:port]` 单源）。
- **加密**：Windows DPAPI（`ConvertFrom-SecureString` 无 `-Key` 径——Microsoft 文档逐字已核；经系统 PowerShell 宿主）。**密钥来源 = 本机用户账户**；值经子进程 stdin、密文经 stdout（零 argv / 零 env / 零日志）；超时有界；编码 UTF-8（非 ASCII 用例在表）。
- **交互**：窗内 `save` 勾选（`checkbox` 字段类——三端渲染差在册：CLI = y/n 步 ∥ VSC / 桌面 = 原生复选框）；**缺省不勾**（opt-in——有意例外须显式）；认证成功后才写；写失败不影响连接。
- **三故障 fail-soft**：解密失败 / 档损坏 ⇒ 回落窗 + 条目保留；条目被服务端拒 ⇒ 删条目 + 回落窗；档缺失 ⇒ 静默视同无。（全部 = 可读句 + 窗恰一次 + 连接不崩。）
- **删除面**：`credentials`（只读清单——值零出现）∥ `forget`（写——过审批门）；删除 ⇒ 下次连接回落窗。
