- **形态**：**非壳页**（卡多——沿看板页先例；不扩「钉表五页」）；**六面**（必交面——需求 §5 沙盒块 14:08 行；机制全文 = `sandbox/SANDBOX.md` §3/§8；**分批落**：① + 容器区 = runner-admin-console 批（**sandbox-docker-admin 批续扩：容器面补齐 + 镜像区**）∥ ②–⑥ 随后续沙盒批）：
  - **① 运行面**（**运行面批落定**——机制 = `sandbox/SANDBOX.md` §3）：卡行 = 可用性提示（无节点 ∥ 全离线 ⇒ 提示条 + 原因；**不整页禁用**——节点面恒可用）+「添加节点」钮；节点表 = 名 ∥ 地址 ∥ 在线态（在线/离线徽标——离线行红标）∥ 版本 ∥ 容器（运行中/总）∥ 操作（展开容器 ∥ 删除）。
    **添加节点弹窗**（公共 `modal.mjs`）：名称 ∥ 地址（占位 `http://10.0.0.6:2375`）——提交 ⇒ 自检中态 ⇒ 成：关窗 + 刷新 + 提示；败：窗内就地错误（逐句人话）+ 不关窗 + 草稿不丢。
    **删除节点弹窗**：读容器清单 ⇒ 有容器 ⇒ 列数 + 二选一（保留 ∥ 连删）+ 确认；无容器/不可达 ⇒ 单确认（不可达明示「容器无法核对——如有将保留运行」）。
    **容器区**（节点行展开——懒加载）：容器表（名 ∥ 镜像 ∥ 状态（已创建/运行中/已退出/原值兜底）∥ 操作：详情/启动/停止/重启/日志/删除（六钮——启/停分列））+「创建容器」钮；**创建容器弹窗**：名称 ∥ 镜像（**节点本地镜像选单**（选定回填下方镜像，可再改；「自定义（手输）」保底——读败/空表/预填不在表 ⇒ 手输照常；轻通道笔 2）∥ 预填设置 `image` 值）∥ 卷（可选，空 = 不挂）；删除容器确认弹窗（运行中将强停强删提示）；
    **镜像区**（sandbox-docker-admin 批——同展开懒加载）：镜像表（名（多标签逐行 ∥ 无标签 ⇒「无标签」）∥ 大小 ∥ 创建 ∥ 操作：删除）+「拉取镜像」钮；**拉取镜像弹窗**（引用输入 `名[:标签]`；在飞态 =「拉取中……（可能持续数分钟）」+ 钮禁用；sandbox-image-quick-pull 批：可选预填（目录窗径）+ 「目标节点：{name}」行**恒显**（手动径也显示——P1 已裁采纳，用户 2026-10-11 18:33）；
    **sandbox-pull-by-source 批：「经由源」选单**——源清单读时读（零新端点）；选定 ⇒ 引用按源组装（输入框可见改写 ∥ 可再改）；不选 = 原样；一键拉取径 ⇒ 选单认源态；窗重开预选上次所选（记忆——预选态非自动改写；P2 已裁采纳，用户 2026-10-11 18:33）；无源 ∥ 读败 ⇒ 不选态 + 一句人话（拉取不阻断））；
    **删除镜像确认弹窗**（勾选「强制删除（被已停止容器引用或多标签时）」——缺省不勾）；**本地镜像表过滤**（sandbox-docker-admin 批——表上方关键词输入：名/标签匹配；无匹配 ⇒ 空态句；零新端点）；
    **镜像源卡（sandbox-image-sources 批；机制全文 = `sandbox/SANDBOX.md` §3）**：卡面 = 源表（名 ∥ 地址 ∥ 面型提示（Hub 面/标准 v2——由 `kind` 派生）∥ 操作：目录/改/删）+「添加源」钮；
    **增/改弹窗**（复用 `modal.mjs`：常用源预选下拉（七条——选中回填名 + 址，可再改）+ 名 ∥ 地址两输入；提交 ⇒ 关窗 + 刷新 + 提示；败 ⇒ 窗内就地人话 + 草稿不丢）∥ **删除确认弹窗**（后果句：只删清单行，不动镜像；非原生 `confirm`）∥
    **目录浏览窗**（懒取：仓库列表（过滤输入 + 截断提示 + 空态句）⇒ 点行取标签列表（过滤输入）；Hub 源 ⇒ 仓库面改走「按镜像名查标签」单输入（目录面 `unsupported` 人话呈）；
    读绪五分类（`timeout`/`unreachable`/`auth_required`/`unsupported`/`bad_response`）各一键文案——窗内就地呈，不关窗）；
    本区件 = `views-sandbox-containers.mjs` ∥ `views-sandbox-images.mjs`（本批拆档——`views-sandbox.mjs` 增量将越 500 硬线前外拆；公共弹窗体（`showNote`/`field`/`submitThen`/`confirmModal`）迁 `modal.mjs`）
    **一键拉取（本批——sandbox-image-quick-pull 批；机制全文 = `sandbox/SANDBOX.md` §3）**：目录浏览窗仓库/标签行尾「拉取」钮（`tiny`）⇒ 出**节点选单**（在线节点行——可点行；题「拉取到节点」）⇒ 既有拉取窗预填逐值（`<主机>[:<端口>]/<仓库>:<标签>`——去 scheme ∥ Hub 主机统一 `docker.io` ∥ 仓库行 `:latest`；
    预填可改；窗内「目标节点：{name}」行恒显）⇒ 确认走既有拉取径（零新端点）；无节点 ∥ 全离线 ⇒ 钮禁用 + 一句人话（复用运行面文案；目录窗打开读一次概览——读时读）。
    **托管接入（托管接入增补——#1236/#1237）**：「托管接入」钮（与「添加节点」并列）∥ **托管接入弹窗**（主机地址 ∥ SSH 端口（缺省 22）∥ SSH 用户 ∥ 认证 = 密钥/密码 + 秘密输入 ∥ sudo 口令（可选）∥ 名称（可选——缺省取探测主机名）∥ 模型（下拉——源 = provider 注册表现有模型）∥ 凭据处置（用完即弃（默认）/保留）；**窗内预告知句**：开 API 监听需重启 Docker ⇒ 既有容器短暂中断（S5；`sandbox/SANDBOX.md` §3）；提交 ⇒ 闭窗 + 装机任务在列；失败 ⇒ 窗内就地人话）∥
    **装机任务区**（表：主机 ∥ 状态（装机中/已就绪/失败）∥ 当前步 ∥ 时间；展开 = 步骤清单 + 读数（失败 = 停在哪步 + 原因人话）；**在途 3s 读时轮询、定终态停**；keep 态「撤销凭据」钮（二次确认）；重试 = 重开弹窗重填——凭据不预填；机制 = `sandbox/SANDBOX.md` §3）
  - **② 工作区**（列表：名/负责人/绑定 runner/盒状态/dirty/快照/资源覆写；动作 = 启动/停止/销毁（二次确认）/轮换 key（拆容器重建——卷保留）/快照恢复；写入口 = **每工作区覆写**（资源 + TTL——行内编辑；`PATCH /api/admin/sandbox/workspaces/:id`；生效 = 下次建盒/重建））
