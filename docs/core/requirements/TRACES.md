## 2. 功能性需求

### 2.1 本子系统条目

- **【派生 · 非用户原话】** 轨迹存储归一为**核内单一实现**（目录 / 命名 / 字段同一形态）；容量与清理策略取一侧（**完整落盘 + 每写 prune**）——两端默认关 ⇒ **无升级破坏**。
  源 = 设计档 `TRACES.md` §2.1 #116 · §3.1 A21 · §4.1 第 10 行。

### 2.2 适用工作流条目（回指 · 不复制）

| 条目 | 适用于本子系统的哪一面 |

### 2.3 启动 / 运行面：清理不得全量线性扫描

- **F-SL3（清理面性能边界）**：① 清理须有**目录级判据**（整日目录过期 ⇒ 整删，免逐文件 stat）；② 每写 prune **须节流**（同窗多次写 ⇒ 至多一次扫描）；③ 存量一次性清理可执行。判定句：`--version` 类一次性命令印出后 ≤0.5s 退出；同窗 3 连写 ⇒ 扫描 ≤1 次；存量清理后 `.jsonl` 总量回落。
- **边界**：不改「完整落盘 + prune」策略裁决本身 · 不动保留期内轨迹 · 两端默认开关零改 · 不改字段 / 目录命名形态。
- **验收**：同 SESSION §2.4 读数口径 + 本档判定句；三端测试全绿。
