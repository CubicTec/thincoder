## 2. 机制

### 2.1 页形（`#/admin/mcp`——管理组；导航顺位 = 管理·模型 后）

- **表**（数据面 = `GET /api/admin/mcp`）：

| 列 | 取值 |
|---|---|
| 名称 | `name` |
| 传输 | `transport`（`stdio`/`http`/`ws`——域语汇三值） |
| 目标 | `target`（stdio ⇒ `command`；http/ws ⇒ 地址——**零秘密**：`token`/`headers` 零下发） |
| 启用 | 勾选（即时写——`PATCH /api/admin/mcp/:id { enabled }`：成功 ⇒ 行态随新数据；失败 ⇒ 红条 + 勾选回读） |
| 操作 | 「探活」∥「改」∥「删」三钮 |

- **探活（行内）**：点「探活」⇒ 该行读数行（在飞 =「探活中……」+ 钮禁用 ∥ 成 = 具名形 `✓ {toolCount} 个工具：{tools}，{latencyMs}ms`；缺名 ⇒ 计数形回落 `✓ {toolCount} 个工具，{latencyMs}ms`——零回归 ∥ 败 = `✗ {error}` 就地错态）——读数两形 = `probeReadoutText`（`mcp/MCP.md` §3.3）；探测 = `POST /api/admin/mcp/probe` 体 `{ id }`（**零副作用**——不进会话 ∥ 不动库）。
- **添加钮**（页首）⇒ **增/改弹窗**（公共 `modal.mjs`——**同窗体两态**）：名称 ∥ 传输方式（`stdio`/`http`/`ws` 三择——切换显对应字段组）：
  - `stdio`：命令（单行）∥ 参数（**每行一条**——多行输入；编辑态**逐值回填 + 差异提交**：改 ⇒ `args` 逐值下发；未改 ⇒ 体不携 `args`（库零变）；清空 ⇒ `args: []` 显式清）∥ 环境变量（**`KEY=VALUE` 每行**——多行输入）；
  - `http`：地址（url）∥ 请求头（同 KV 行形）∥ 令牌（password 输入）；
  - `ws`：地址（wsUrl）∥ 请求头 ∥ 令牌；
  - 启用勾选（缺省勾）∥ 窗内「测试」钮（**草稿探活**——体 = 表单当前值；编辑态秘密字段留空 ⇒ 服务端回落库内值——`mcp/MCP.md` §3.2）。
  - **编辑态秘密字段**：零回填——只示「已保存——留空 = 不变」提示行 + 「清除」勾（勾 ⇒ 显式 `null` 清空；沿 providers 清除勾先例）。
  - 提交 ⇒ 成：关窗 + 刷新 + `flash`；败：窗内就地人话（400/404）+ 草稿不丢。
- **删除确认弹窗**（非原生 `confirm`——`confirmModal` 复用）：后果句（「该服务器的工具将不再对管理会话可用」）→ `DELETE`。
- **空态**：一句引导（「添加 MCP 服务器后，管理会话将获得其工具（如 web 搜索）」）。
- **动作在飞态**：提交/删除钮禁用（沿 KD-SV-46 口径——弹窗提交钮级；行内不设整行闩——本页动作非并发敏感）。

- **最近先例（对齐 ∥ 偏离）**：①「添加节点」弹窗自检中态 + 窗内就地错误 + 关窗刷新（`views-sandbox.mjs`——`webui/SANDBOX.md` §2.1①）——**对齐**（提交在飞态 ∥ 成关窗刷新 ∥ 败窗内人话）；② 主机凭据弹窗**密文零回填**（`host-credential.mjs`——`webui/SANDBOX.md` §2.1① 主机凭据块）——**对齐**（秘密只进不出 + 「留空 = 不变」）；
  ③ Provider「测试连接同窗」**草稿口径**（`webui/ADMIN.md`；AC-18）——**对齐**（未保存亦可先验；留空回落库内值）；**偏离** = 行内读数行（探活结果就地呈——先例为弹窗读数行/全局行；本页多行多探——行级归属更直读）。

## 5. 边界（本面不做）

- 秘密回填/查看/导出（密文零回显——沿主机凭据纪律）。
- 工具管理面（每服务器工具明细/逐个开关/白名单——不在本页；探活读数 = 探测所返计数 + 工具名（只读显示面）——机制 = `mcp/MCP.md` §2.2 ∥ §3.3）。
- 探活历史/自动巡检（手动动作；零落库）。
- 排序/搜索（清单规模小——未点，不发明）。
