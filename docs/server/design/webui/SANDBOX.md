## 2. 机制

### 2.1 沙盒页（管理——`#/admin/sandbox`）

- **形态**：**非壳页**（卡多——沿看板页先例；不扩「钉表五页」）；**六面**（必交面——需求 §5 沙盒块；机制全文 = `sandbox/SANDBOX.md` §3/§8）；
  **分标签**：页形 = 页题 + 两标签（公共件 `tabs.mjs`（已落）——机制 = `webui/TABS.md` §2.1）——「运行面」 ∥「镜像与镜像源」；②–⑥ 余面落位时标签归属 = 落位时定（不预设）：
  - **① 运行面**（机制 = `sandbox/SANDBOX.md` §3）：卡行 = 可用性提示（无节点 ∥ 全离线 ⇒ 提示条 + 原因；**不整页禁用**——节点面恒可用）+「添加节点」钮；节点表 = 名 ∥ 地址 ∥ 在线态（在线/离线徽标——离线行红标）∥ 版本 ∥ 容器（运行中/总）∥ 操作（展开容器 ∥ 删除 ∥ **「连接」**——连接方式编辑）。
     **添加节点弹窗**（公共 `modal.mjs`）：名称 ∥ 地址（占位 `http://10.0.0.6:2375`）∥ **连接方式段**：二择「明文（缺省）∥ TLS 客户端证书」——TLS 档显三件输入（CA 证书 ∥ 客户端证书 ∥ 客户端私钥——多行输入；**零回填**）；
    提交体按档携 `connection`/`tls`——缺省档不携键（零行为变化）；档与地址 scheme 相抵/缺件 ⇒ 窗内就地人话（400）——提交 ⇒ 自检中态 ⇒ 成：关窗 + 刷新 + 提示；败：窗内就地错误（逐句人话）+ 不关窗 + 草稿不丢——
    **+ 节点侧接线提示块**（说明句（含 TLS 档「证书 = 用户自备」）+ 命令文本 `<pre class="snippet">` 可选中；**复制钮按可用性门**——`navigator.clipboard` 在场 ⇒ 钮在场、缺 ⇒ 零钮（零假控件）；文本源 = `sandbox/SANDBOX.md` §3「节点侧前置」）。
    **删除节点弹窗**：读容器清单 + 承载工作区清单（**并行**）⇒ 有容器 ⇒ 列数 + 二选一（保留 ∥ 连删）+ 确认；无容器/不可达 ⇒ 单确认（不可达明示「容器无法核对——如有将保留运行」）；**有承载工作区 ⇒ 警告句（N + 名——沿服务端 400 同款措辞）+「确认丢弃」勾选（缺省不勾 ⇒ 删除钮先禁、勾后启；提交体携 `confirm: true`）**；无承载/不可达 ⇒ 体不携 `confirm`（现行两径零回归）。
     **容器区**（节点行展开——懒加载；**展开体 = 容器区 + 卷区——镜像区迁标签②**）：容器表（名 ∥ 镜像 ∥ 状态（已创建/运行中/已退出/原值兜底）∥ 操作：详情/启动/停止/重启/日志/删除/终端（七钮——启/停分列；第七钮「终端」））+「创建容器」钮；
    **动作钮状态门 + 忙态 + 反馈**：门矩阵 = 运行中 ⇒ 启动禁 ∥ 停止可用 ∥ 重启可用；非运行（已创建/已退出/原值兜底）⇒ 启动可用 ∥ 停止禁 ∥ 重启禁；
    重启锚定运行中（设计拍——重启语义 = 对运行中容器「停 ⇒ 启」；非运行态该钮与「启动」重复、成功句「已重启」失实）；详情/日志/删除/强杀不随门（读面任意态有意义；删除任意态可删——强停强删提示在窗；强杀 = 兜底语义——未运行 ⇒ 服务端 409 人话既有）；
    点击 ⇒ 该行七钮即时禁用（六钮 + 第七钮「终端」——同拍入闩：窗类入口在飞期一律不可开；`disabled` 非 `hidden`——避 display 压属性坑）+ 行闩（在飞零第二请求）⇒ 完成即恢复 = **回门矩阵态**（成功面另走既有 `invalidate()` 重取——态列随新数据重渲；失败面按当刻态列重算——非六钮无条件全启，否则运行中容器「停止」失败后「启动」瞬时可用，与门矩阵相抵）；成功 ⇒ `flash` 成功句（含容器名——三动作各一键）；失败 ⇒ 红条照旧（`ctx.fail`）。
    闩覆盖面 = 该行七钮（六钮含「详情」＋第七钮「终端」——在飞期窗类入口一律不可开；同拍）∥ 详情窗内动作（强杀）不入忙态口径：窗在场 ⇒ 背景 inert（`modal.mjs:3` 原生 `<dialog>` 模态 ∥ `:10` 单例一窗）⇒ 行钮不可达——两向互斥，闩无需提级覆盖窗内入口。**闩 = 渲染实例态**——他行动作成功重渲同节点时闩复零，窄窗内可对同容器再发一次（服务端幂等收编；AC-49 ② 不受影响——父侧裁：接受现状、补此句）。

     对齐 = 同口径（禁用 + 既有反馈件——零新样式件）；偏离 = 行级七钮联动（六钮 + 第七钮「终端」——同拍） + 行闩（先例为单钮 ∥ 弹窗提交钮级）；重启门（运行中锚定）无直系先例——设计拍。
